# 退款记在租户名下,从预收余额出

向租户退钱时,同样不指定是哪一笔账,只记:哪个租户、哪天、多少钱。
退款先从预收余额扣,余额不足则意味着实际上是在冲减欠款 —— 这两种情况都允许。

## 为什么

跟收款保持同一个形状,账才对得上:钱进这个人的账,也从同一个账出。
如果退款单独挂某笔应收,又回到"要人手工指认哪一笔"的老问题。

## 退租结算

退租时一次算清:本租期应收合计、已收合计、差额谁补给谁。这时退款与收款都可能发生,
都由上述两条规则覆盖,不需要额外的结算科目。
