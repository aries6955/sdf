# 没有删除,只有退租与换下

`households` 与 `meters` 不删除进入过账本的记录。
`meters` 只有一个例外:从未有过读数、缴费、换表记录、未在用、且没有分表挂在下面的空白表,
可以在表管理里直接删除(录错新建表时的撤销)。

- 租户离开 = **退租**:录终读数、结算本租期、关闭租期。台账历史全部保留。
- 表退休 = **换表**:录旧表终读数与新表基数。旧表标记为已换下,读数与小票全部保留。

## 为什么

修复前两个删除按钮都会在有账时直接 500(`FOREIGN KEY constraint failed`),
而即便修好外键,删掉也等于把历史从账本上撕掉 —— 三年后想查"2025 年 3 月甲交没交"就再也查不到。

真正需要"删"的只有录错的新手误(建错一个名字)。空白表没有任何账本痕迹,
删掉不会撕账;一旦有读数/账单/换表/在用,删除一律拒绝 —— 为零星的录入错误保留一个能毁掉历史的按钮,不划算。

## 代价

- 表名录错可以改;空白表可删,有历史的表只能换表。可接受。
- 表一旦"换下"就无法再从列表里彻底消失。可接受:已换下的表本就该留痕。

## 相关

- 表只有在用/已换下两种状态,不存在"停用"。见 [ADR-0014](0014-billing-periods-span-meter-changes.md)。
