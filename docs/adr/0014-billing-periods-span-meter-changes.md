# 账期沿计量线连续,换表不切断账期

账期不属于某一块表,属于一个租户名下的"计量线"(水一路、电一路,同路可有多条)。
换表时账期不切断:旧表终读数与新表基数在同一日期录入,本账期用量 = 旧表段 + 新表段,合并成一张账。

## 为什么

租户关心的是一段时间用了多少水、多少电,不关心期间换过几块表。修复前的系统把换表当成两次账期的分界:
旧表结一张、新表从基数重新起算一张,同一个月的费用被拆成两张单。租户拿到两张单会问"为什么这个月两张",
而真实的计量只是换了个表壳。

相加本身是正确的:两块表读数不重叠,旧表段 + 新表段恰好覆盖整段用量。

## 具体规则

- 单价取"结账那次抄表"上填的租户单价,对整段生效。与"单价不按日期拆段"一致。
- 换表是表退休的唯一方式,不存在"停用不换"。分表坏了必换。
- 换总表时,原接入它的分表改接到新总表;分表的账期不受影响(总表不参与计费)。

## 代价

- 账期要跨表,所以用量不能简单用 `value - prev_value` 算,得按段累加。计费逻辑复杂度上升。
- "抄表记录挂在计量线上、另记取自哪块表"必须做对,否则换表那次的读数会丢归属。
