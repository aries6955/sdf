# 归属只来自租期,表上不再存租户字段

一块分表"现在归谁"由租期决定:谁在什么日期、用什么读数入住,谁在什么日期、用什么读数退租。
`meters.household_id` 这个冗余字段废除,读取归属一律走同一个函数。

## 为什么

冗余字段和租期会打架。修复前的系统里,`billing.py` 用租期算账期,而 `/readings/bill` 用
`meters.household_id` 写应收 —— 实测:甲把表交给乙之后,再给甲最后一期出账,应收记到了乙名下。
统计页按租期算出是甲,台账记的是乙,两张表对不上,而且没法判断哪张对。

"一个租户用多块表"不需要这个字段也能表达:同一租户名下挂多条租期即可。

## 代价

- 每次"现在归谁"都要查租期,不能一步 join 出来。数据量在千行级,用视图/单函数封装即可。
- 表列表要显示持有人时需额外查询。可接受。

## 相关

- 一并废弃的字段:`meters.household_id`、`meters.active`(表只有在用/已换下,由换表历史推出)。
