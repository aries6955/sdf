# 抄表不可按日期拆价,允许补录到中间

## 单价只认抄表那一条

一个账期只用一个单价:结账那次抄表上填的租户单价,对该账期整段生效。
账期内调过价、或账期内换过表,都不拆分。

理由:拆价等于要求系统记住"从哪天开始涨",还要支持区间内再分段;而现实中调价是口头的事,
差个几块钱谁也不会算。与 [ADR-0003](0003-per-reading-unit-price-with-last-value-default.md)
"单价归属本次账期"一致。

## 读数允许插到中间

漏抄一个月、手上留着纸条,可以把读数按真实日期插到已有序列中间。
插入后,前后两个账期各自重算。

修复前的系统只允许"晚于上次",补录只能把日期改成今天硬塞,整个账期序列从此错位。

## 约束

- 插入的读数必须不小于前一条、不大于后一条(三相表逐相校验),否则用量为负。
- 已收款的账期不能插入或修改,须先删除对应收款。
- 补录只能落在**当前挂在这条计量线上的表**上。旧表一旦换下就不再接受新读数 ——
  换表时旧表的终读数必须当场录准,事后补录换表前那段不受支持。
