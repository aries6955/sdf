# 缴费只是流水,不对租户计费

缴费记录只用于对账:照部门账单录入缴费日期、总表、读数、单价、金额。
它与租户单价之间没有任何关联或校验。

统计页并排展示:向部门缴了多少、向租户收了多少、以及两者之差(毛差)。
日期区间按用户选择的时间范围对齐,不做"按账单周期对齐"之类的猜测。

## 为什么

水电费房东多数是赚的,这是这门生意的常识。两边单价不同不是异常,不做差异告警。
修复前的系统允许手填金额覆盖计算结果、且不记录原因,看起来就像个错误;
真相是账单本来就不该由系统算 —— 见 [ADR-0013](0013-main-meters-have-no-base.md)。

## 相关

- 毛差只做展示,不参与任何账务计算,不影响应收/实收/欠款。
