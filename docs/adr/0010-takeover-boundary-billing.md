# 账单按租期边界分段

租户会换手,表不会换。为让同一块表在不同租户名下正确计费,引入租期(takeovers)记录:
每块表从哪个读数起归哪个租户。交接读数是共享边界 —— 它是上一任的最后一段账单的终点,
也是新租户的起点;同一行读数既结上段也开下段,保证用量不被重复计量,也不被遗漏。

由此:

- 新增租户时必须选择使用的表并录入交接读数。
- 表转给新租户后,上一任的历史账单仍然完整可查。
- 换表 = 新表继承旧表租户,并为新表建立租期。
- 删除租户只解绑表并清除租期记录,读数保留。

替代了早期"meter.household_id 即全部归属"的模型 —— 那个模型在换手后会把历史用量算到新租户头上。

> **后续**:本 ADR 的核心判断(归属按区间记录、换手后历史账单仍可查)被 ADR-0012 继承。
> 但它把归属记在"表"上、把换表当成切断账期的动作,已被 ADR-0014 推翻 ——
> 账期沿计量线连续计算,换表只是换了物理表。
