# 水电费管理

单用户本地 Web 应用,管理房东总表与住户分表的抄表、用量和费用。

## 运行

```bash
cp password.example.txt password.txt          # 编辑其中的登录密码
uv run uvicorn app.main:app --host 127.0.0.1 --port 8000
```

浏览器访问 http://127.0.0.1:8000 。改密码请编辑 `password.txt` 并重启服务(Web 界面不提供改密码)。

数据保存在项目目录的 `data.sqlite3`,由单进程独占写入。

## 测试

```bash
uv run pytest -q
```

## 使用流程

1. **初始化**:录入房产名称;住户(每行一户);表具(`名称,水/电,总/分,所属总表,住户`);各表基数(`表名,日期,读数,部门单价,租客单价`)。
2. **抄表**:默认带入该表上次单价,可改;读数必须不小于上次、日期必须晚于上次。
3. **换表**:一次操作完成停用旧表、旧表终读数、新表基数、启用新表;单价自动沿用。
4. **缴费**:记录向部门缴费的日期、金额、总表与覆盖账期,仅作记录,不锁定账期。
5. **出账**:标记后该账期读数和单价锁定,修正须走冲正记录。
6. **统计**:按住户/表/账期区间/出账状态/水电类型筛选,显示用量与金额合计、冲正汇总与应收净额,可导出当前查询结果为 PDF。

## 关键规则

- 只有分表产生住户账单;总表只用于与部门缴费对账,不对住户计费。
- 住户没有分表就不产生账单,需要计费就先装表。
- 水电分别独立建模,共用住户与账期。

## PDF 字体

PDF 导出默认使用 `C:/Windows/Fonts/simhei.ttf`;其他平台可通过 `SDF_PDF_FONT` 环境变量指定中文 TTF 字体路径。
