# 收款记在租户名下,按最早欠账优先自动冲抵

收到一笔钱时,只记:哪个租户、哪天、多少钱。不指定它对应哪一笔应收。
系统按账期从早到晚自动冲抵;超出全部欠款的部分转为该租户的**预收余额**,用于抵扣后续应收。

## 为什么

现实中拿到的是"甲转了 300 块",不是"甲付了哪一笔"。修复前的系统要求指定 `receivable_id`,
一笔转账覆盖多期就得手工拆成多条记录;拆错要删掉重来,而拆错本身很难发现。

"先欠的先还"是双方都不会争议的规则,不需要教,也不会错。

## 预收余额

超出欠款的部分不拒收,存为该租户的余额。预交几个月、顺手把押金一起给,都是常态;
拒收会逼人把真实的钱记成不真实的数字。

## 退款

退款同样记在租户名下,从预收余额中出。跟收款走同一条路,账才对得上。

## 代价

- 看不到"这一笔收款是哪天付的第几期账",只能看到冲抵结果。需要时可从余额变动倒推。
- 冲抵规则一旦确定,改变它会重排历史账目的口径。这条规则必须写进测试。

## 相关

- 继承 [ADR-0011](0011-receivable-receipt-ledger.md) 的应收/实收两线拆分。
- 取代 ADR-0011 中"收款不得超过应收"与"退租前必须结清欠款"两条。
- 取代 [ADR-0018](0018-refunds-and-balance.md) 之前的"收款指定账单"模型。
