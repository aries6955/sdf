# 总表读数与分表读数互不对应

各分表读数之和不一定等于总表读数,部门结算用的总表读数自成一条序列。因此:

- 缴费时的「上次读数」只取自该总表的上一次缴费记录,不取自抄表页的读数。
- 部门单价在缴费时录入,不在抄表时录入。
- 抄表页的总表读数仅作参考记录,不参与缴费金额的计算,也不参与住户计费。

supersedes ADR-0003 中「部门单价在抄表时录入」的部分。租客单价仍在抄表时录入(ADR-0003 对租客单价的部分继续有效)。

> **后续**:本 ADR 保留"总表与分表是两条互不对应的序列"这一判断,它仍然成立。
> 但它推出的"缴费时按上次读数差 × 单价算金额"已被 ADR-0016 推翻 ——
> 房东根本不抄总表,账单上的数字照抄即可。
