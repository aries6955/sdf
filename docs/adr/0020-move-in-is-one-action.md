# 入住是一个动作:一次录完表与读数

新增租户 = 它住哪几块表 + 每块表当日的读数,一屏一次提交。
同一路可以选多块表(甲有两块水表就选两块);三相表那一行可以填三个分相读数。

只能从"已装好且当前空着"的表里挑选。新建表不在入住流程内,必须先到表管理里建好。

## 为什么

修复前的系统把这件事拆成四步:建表 → 建租户 → 绑表 → 录基数,任何一步漏了数据就是半截,
而且基数的入口散在两处(表设置页的"起始读数"和新增租户页的"交接读数"),同一件事被存了两份。

现实中房东就是拿张纸写下"甲、101、水 100、电 1000",一次写完。

## 代价

- 入住表单随表数量增长而变长。表少,可接受。
- 装表与入住不能在一次操作里完成。这是刻意的:表是长期资产,租户是短期关系,两者的录入时机不同。
