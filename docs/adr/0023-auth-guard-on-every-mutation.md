# 所有提交动作统一校验登录

除了 `/login` 与 `/logout`,全部路由(含所有 POST)都走同一处登录校验。

## 为什么

修复前 36 个路由里,只有 GET 做了 `require_login`;28 个 POST 全部裸奔 ——
任何人或任何页面只要往系统发一条请求,就能清空全部数据、删掉租户、改账。

单机使用碰上概率不高,但这是白捡的洞:一处中间件就能管住全部,没有副作用。

## 代价

- 中间件无法使用"按路由粒度放行"的简单写法,需要对 `/login`、`/logout`、`/static` 显式放行。
- 登录态仍存在进程内 `_sessions`(单进程,见 [ADR-0006](0006-single-process-local-web-with-fastapi.md)),重启后所有人需要重新登录。保持现状。
