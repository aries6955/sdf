# 05: 修好示例数据里的三相读数

**What to build:** 示例数据里的三相电表读数在换表与退租两处被写成了单个合计值,
读到这些历史数据时逐相显示会露馅。修好它,让示例数据里的三相表在三处都带齐三相读数:
入住、抄表、退租。
这一项独立于其他改动,可与其他票并行。

**Blocked by:** None (can start immediately)

**Status:** wontfix

- [x] 示例数据中三相电表的每一条读数都带齐三相数值,且三相之和等于该条读数的合计
- [x] 退租后的三相记录不再出现缺失分相
- [x] 换表涉及三相表时同样带齐分相
- [x] 示例数据的合计用量与各期金额不因本次修正而改变
- [x] `uv run python scripts/check.py` 全过
