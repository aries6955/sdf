# 总表不存基数,读数与单价以部门账单为准

总表在系统里只保留:名字、水还是电、装在哪天、换下时间(换表时)。不存基数、不存读数序列。

每期缴费时照部门账单手填:缴费日期、总表、读数、单价、金额。系统不推算金额。

## 为什么

房东本人不抄总表 —— 总表由水务/电力抄,账单寄来才交钱。因此:

- 总表的读数序列是部门给的,不是房东录的,系统没必要维护一条"自己的"序列。
- 账单金额可能含阶梯价、滞纳金、补收、抄表误差,不可能由"读数差 × 单价"复原。
  [ADR-0009](0009-main-meter-readings-independent-of-sub-meters.md) 推出的"按上次读数差算金额"
  会逼人为了让系统算得对而篡改账单上的真实数字。

## 代价

- 缴费记录不能做算术校验,录错只能靠人看。接受:它本身就是照抄账单的流水。
- 总表读数不再是一个可信的"当前表码",只能看到每次账单上的读数。接受。

## 相关

- 取代 [ADR-0009](0009-main-meter-readings-independent-of-sub-meters.md) 中"按读数差 × 单价算缴费金额"的部分。
- 抄表页不再列总表(总表读数只在缴费时出现)。
