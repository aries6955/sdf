# 02: 读数只经一个读数录入模块写入

**What to build:** 任何写读数的动作——入住、抄表、改读数、撤回读数、换表的两面读数、退租——
都经由同一个模块,模块内部完成三相合成、日期先后、隔表逐相比较、已收款锁定,并在需要时触发账期重算。
拒绝时模块抛出携带中文文案的异常,路由把它原样作为提示条显示,因此所有既有页面文案一字不变。
路由层因此只剩"要记录哪一种读数"。
