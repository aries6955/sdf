# 账务分为应收与实收两条线

出账只锁定读数并生成一条**应收**;实际收款单独记录,金额可小于应收、可分多次。
欠款 = 应收合计 + 冲正 − 实收合计。收款不得超过应收。退租前必须结清欠款,退租只解绑表、
保留台账历史。

选择这一模型而不是"出账即已收",是因为房东收款时间不固定且常有收不够的情况;
把收款从出账里拆出来,才能看清每个租户欠多少、欠多久。

> **后续**:"应收与实收两条线"这一拆分仍然成立,被 ADR-0017 继承。
> 但三处细节已被推翻:冲正已删除(ADR-0015)、收款改为记在租户名下自动冲抵而非指定账单(ADR-0017)、
> 退租不再要求收齐尾款只要求结算清楚(见 GLOSSARY「退租」)。
