# 空档期用量归房东,算出但不收费

上一任退租与下一任入住之间,表无人使用,这段读数差归房东:
算出并展示,但不进任何租户账单,不收任何人的钱。

## 为什么

没住人就没有该收费的租户。早期模型用一个"差额户"来承担这类量([ADR-0001](0001-difference-household-absorbs-meter-gap.md)),
但它需要一个"哪一户来承担"的约定,而这户往往既不是真实租客、也可能随情况变化,账单归属含糊,
已被 [ADR-0008](0008-drop-difference-household.md) 推翻,不请回来。

## 为什么要算出来

空档期的用量是白交的钱,也可能是漏水。算出来能让人察觉"这中间怎么用掉 18 吨"。
只算不收,不会给账单添乱。

## 相关

- 与"归属只来自租期"配套:空档期没有租期,因此不存在归属。[ADR-0012](0012-tenancy-is-the-only-ownership-source.md)
