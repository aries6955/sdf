# 抄表即成账,取消手动出账;删除冲正

抄一次表,当场把这个账期算成一条应收。不再有"出账"这个按钮。

原来的"冲正记录"(对已出账账期加减一笔)整体删除。

## 为什么

抄表就是在说"这一段结束了,量是这个数"。既然量已确定,钱当场算出来是零成本的;
而"抄了但没点出账"制造了一个中间状态:既不算欠款也不算已收,只能靠人记得回头点一下。
修复前的系统里,这个状态还导致单价可以被事后悄悄改变 —— 出账时重算一遍,与抄表时看到的数不一致。

冲正之所以能删,是因为它想解决的每种情况在别处都有出口:

| 原冲正用途 | 现在的出口 |
| --- | --- |
| 抄错数 | 未收款时直接改读数,账单随之重算 |
| 收错了 | 删掉收款,账期解锁重算 |
| 少收/多收 | 实收本来就允许多次、可少于应收 |
| 退租时抹零/找齐 | 退租结算一次算清 |

修复前冲正是第三条并行的钱:它不进应收表,只在台账里加到 `total_due`、在统计页加到 `net_amount`、
在首页被描述成"已计入应收" —— 三个页面三种口径,对不上账。删掉后只剩应收与实收两条线。

## 收款的锁定边界

钱没收之前,读数随便改。一旦开始收款,这条账期锁死;要改必须先删收款。

## 代价

- 抄错一次就产生一条错账,必须手动修改才能纠正(以前可以先抄着、不点出账)。
- 失去"先算出来看看,确认了再正式出账"的缓冲区。实际使用中不需要这个缓冲区。
